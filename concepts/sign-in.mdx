Sign in with Appearance lets users share their reference photos with your service. One tap, no uploads.

## The flow

1. User taps "Connect with Appearance"
2. They see what will be shared and approve
3. Your service receives an access token and can call the API

If the user doesn't have an Appearance ID yet, they create one during the flow.

## Scopes

| Scope | What you receive |
|-------|-----------------|
| `appearance:read` | Reference photos of the user |
| `generations:read` | The user's generation history |
| `generations:write` | Save results to the user's profile |
| `styles:search` | Search styles on Appearance |

## Authorization

```
GET appearance.app/oauth/authorize
  ?client_id=YOUR_CLIENT_ID
  &redirect_uri=https://yourapp.com/callback
  &scope=appearance:read
  &response_type=code
```

Exchange the code for tokens:

```bash
curl -X POST https://appearance.app/api/oauth/token \
  -H "Content-Type: application/json" \
  -d '{
    "grant_type": "authorization_code",
    "code": "AUTHORIZATION_CODE",
    "client_id": "YOUR_CLIENT_ID",
    "client_secret": "YOUR_SECRET",
    "redirect_uri": "https://yourapp.com/callback"
  }'
```

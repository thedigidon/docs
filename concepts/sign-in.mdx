title: "Sign in with Appearance"
description: "OAuth-based identity that shares how someone looks — not just an email address."
---

Sign in with Appearance is an OAuth 2.0 flow that lets users share their appearance data with your app. When a user connects, your app immediately knows what they look like. No questionnaires. No photo uploads. No cold start.

## What makes it different

Sign in with Google gives you an email and a name. Sign in with Appearance gives you a face shape, hair type, skin tone, and facial measurements. The user's experience is personalized from the first interaction.

## The flow

1. User taps "Connect with Appearance" in your app
2. Appearance opens, showing the user their own profile
3. The user sees exactly what will be shared and approves
4. Your app receives an access token and appearance data

If the user doesn't have an Appearance profile, they create one during the flow. A scan takes about ten seconds.

## Scopes

| Scope | What you receive |
|-------|-----------------|
| `profile` | Username, display name, avatar |
| `appearance:read` | Scan grid image and structured appearance data |
| `appearance:photos` | Individual scan angle photos |

Request only the scopes you need. Users see exactly what each scope includes before approving.

## Authorization

```
GET appearance.app/oauth/authorize
  ?client_id=YOUR_CLIENT_ID
  &redirect_uri=https://yourapp.com/callback
  &scope=profile,appearance:read
  &response_type=code
  &state=RANDOM_STATE
```

After the user approves:

```
GET https://yourapp.com/callback
  ?code=AUTHORIZATION_CODE
  &state=RANDOM_STATE
```

Exchange the code for tokens:

```bash
curl -X POST https://api.appearance.app/v1/oauth/token \
  -H "Content-Type: application/json" \
  -d '{
    "grant_type": "authorization_code",
    "code": "AUTHORIZATION_CODE",
    "client_id": "YOUR_CLIENT_ID",
    "client_secret": "YOUR_SECRET",
    "redirect_uri": "https://yourapp.com/callback"
  }'
```

```json
{
  "access_token": "at_...",
  "refresh_token": "rt_...",
  "expires_in": 3600,
  "scope": "profile appearance:read"
}
```

---
title: "Sign in with Appearance"
description: "OAuth-based identity that shares what someone looks like."
---

Sign in with Appearance lets users share their reference photos with your service. When a user connects, you can immediately generate images of them.

## The flow

1. User taps "Connect with Appearance" in your app
2. Appearance shows the user what will be shared
3. The user approves
4. Your service receives an access token and can call the API

If the user doesn't have an Appearance profile yet, they create one during the flow. A scan takes about ten seconds.

## Scopes

| Scope | What you receive |
|-------|-----------------|
| `appearance:read` | Reference photos from the user's face scan |
| `generations:read` | The user's generation history |
| `generations:write` | Ability to save results to the user's profile |
| `styles:search` | Search styles from businesses on Appearance |

Request only the scopes you need.

## Authorization

```
GET appearance.app/oauth/authorize
  ?client_id=YOUR_CLIENT_ID
  &redirect_uri=https://yourapp.com/callback
  &scope=appearance:read,generations:read
  &response_type=code
  &state=RANDOM_STATE
```

Exchange the code for tokens:

```bash
curl -X POST https://appearance.app/api/oauth/token \
  -H "Content-Type: application/json" \
  -d '{
    "grant_type": "authorization_code",
    "code": "AUTHORIZATION_CODE",
    "client_id": "YOUR_CLIENT_ID",
    "client_secret": "YOUR_SECRET",
    "redirect_uri": "https://yourapp.com/callback"
  }'
```

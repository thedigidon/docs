---
title: "Appearance ID"
description: "What you receive when a user connects their Appearance ID."
---

When a user connects their Appearance ID, you receive reference photos of them.

## Photos

An array of reference images showing what the user currently looks like. These are high-quality photos suitable for use as generation input.

```json
{
  "photos": [
    "https://appearance.app/photos/usr_k7Xm/1.jpg",
    "https://appearance.app/photos/usr_k7Xm/2.jpg",
    "https://appearance.app/photos/usr_k7Xm/3.jpg",
    "https://appearance.app/photos/usr_k7Xm/4.jpg"
  ],
  "updatedAt": "2026-03-29T10:30:00Z"
}
```

Photo URLs are signed and temporary. Cache the images if you need them beyond a single session.

## Generations

Every image generated using a user's Appearance ID — from any service — is stored in their profile.

Use `save_generation` to add your results. Use `list_generations` to see what's been created.

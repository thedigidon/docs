When a user connects their Appearance ID, you receive reference photos of them.

## Photos

Multi-angle photos from the user's most recent face scan:

- **Scan grid** — A 2x2 composite showing front, left, right, and expression angles
- **Individual angles** — Separate front, left, and right photos

URLs are signed and short-lived. Cache the images if you need them beyond a single session.

## Generations

Every image generated using a user's Appearance ID — from any service — is stored in their profile. The user sees a unified timeline:

```
Buzz Cut Fade        via Appearance · Apr 12
Curtain Bangs        via ChatGPT · Apr 11
Round Frames         via Claude · Apr 10
```

Use `save_generation` to add your results. Use `list_generations` to see what's been created before.

## What's not included

Appearance captures structured data internally — hair type, face shape, skin tone, measurements, compatibility scoring. This data powers the Appearance app but is not shared through the API in the current version.

---
title: "Appearance Data"
description: "What you receive when a user shares their appearance with your app."
---

When a user connects through Sign in with Appearance, you receive structured data describing what they look like. This data comes from a multi-angle face scan analyzed by AI vision and ARKit facial geometry.

## Scan grid

The scan grid is a 2x2 composite image showing the user from four angles. This is their current appearance as of their most recent reflection.

```json
{
  "scanGrid": "https://appearance.app/scans/usr_k7Xm/grid.jpg"
}
```

The URL is a signed link valid for 24 hours. Your app can display it directly or cache it.

With the `appearance:photos` scope, you also receive the individual scan angle photos.

## Structured fields

The structured data describes what the user looks like using typed, enumerated values.

### Face

| Field | Type | Description |
|-------|------|-------------|
| `faceShape` | `string` | `oval`, `round`, `square`, `diamond`, `heart`, `oblong` |
| `audience` | `string` | `masculine`, `feminine`, `androgynous` |

### Hair

| Field | Type | Description |
|-------|------|-------------|
| `hair.textureFamily` | `integer` | Andre Walker scale: 1 (straight), 2 (wavy), 3 (curly), 4 (coily) |
| `hair.textureLabel` | `string` | Human-readable: `Straight`, `Wavy`, `Curly`, `Coily` |
| `hair.density` | `string` | `thin`, `medium`, `thick` |
| `hair.lengths.top` | `string` | `bald`, `stubble`, `short`, `medium`, `long` |
| `hair.lengths.sides` | `string` | `bald`, `stubble`, `short`, `medium`, `long` |

### Skin tone

| Field | Type | Description |
|-------|------|-------------|
| `skinTone.fitzpatrick` | `string` | Fitzpatrick scale classification |
| `skinTone.undertone` | `string` | `warm`, `cool`, `neutral` |

### Measurements

Physical measurements from ARKit facial geometry, in millimeters.

| Field | Type | Description |
|-------|------|-------------|
| `measurements.faceWidthMm` | `number` | Face width |
| `measurements.jawWidthMm` | `number` | Jaw width |
| `measurements.pdMm` | `number` | Pupillary distance |

## Full response

```json
{
  "scanGrid": "https://appearance.app/scans/usr_k7Xm/grid.jpg",
  "faceShape": "oval",
  "hair": {
    "textureFamily": 3,
    "textureLabel": "Curly",
    "density": "thick",
    "lengths": { "top": "short", "sides": "short" }
  },
  "skinTone": {
    "fitzpatrick": "Type V",
    "undertone": "warm"
  },
  "measurements": {
    "faceWidthMm": 142.3,
    "jawWidthMm": 126.1,
    "pdMm": 63.5
  },
  "audience": "masculine",
  "analyzedAt": "2026-03-29T10:30:00Z"
}
```

Every field is typed and constrained to a known set of values. Your app can use them directly in logic without natural language interpretation.

## What's not included

Appearance captures significantly more data internally — growth patterns, hair condition, facial proportions, styling capabilities. This data powers the Appearance app but is not shared through the API in the current version.

As the platform expands, additional fields and zones will become available through new scopes.

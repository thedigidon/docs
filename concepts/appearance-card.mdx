## What is an Appearance Card?

An Appearance Card is a **compact extract** of a user's Appearance Profile — roughly 25 fields with enum-only values. It's the lightweight format for integrations that need quick access to key appearance attributes without the full 50+ field profile.

Think of it as the difference between a driver's license and a full medical record. The card gives you what you need for most decisions; the profile gives you everything.

## When to Use Card vs. Profile

| | Card | Profile |
|--|------|---------|
| **Fields** | ~25 | 50+ |
| **Values** | Enums only | Mixed (strings, numbers, objects) |
| **Purpose** | Quick reads, lightweight integrations | Deep personalization |
| **Measurements** | No | Yes (mm-precision from ARKit) |
| **User-editable fields** | No | Yes |
| **API Scope** | `appearance:card` | `appearance:profile` |

**Use the Card** when you need key attributes fast — texture family, face shape, density, lengths. Most agent integrations and quick-read scenarios work well with the card.

**Use the Profile** when you need depth — exact face measurements in millimeters, hair condition data, growth patterns, skin tone analysis, glasses fitting. Deep personalization apps and health/beauty contexts benefit from the full profile.

## Schema

<Note>
  Cards are zone-aware. Hair fields are `null` when `zone !== 'hair'`, glasses fields are `null` when `zone !== 'glasses'`.
</Note>

### Universal Fields

| Field | Type | Description |
|-------|------|-------------|
| `cardType` | `'user'` | Always `user` for user-facing API |
| `zone` | `'hair' \| 'glasses'` | Which appearance zone |
| `audience` | `'masculine' \| 'feminine' \| 'androgynous' \| null` | Presentation preference |
| `computedAt` | `string` (ISO 8601) | When this card was generated |
| `cardVersion` | `1` | Schema version |

### Hair Fields

| Field | Type | Description |
|-------|------|-------------|
| `textureFamily` | `1 \| 2 \| 3 \| 4 \| 'bald'` | Andre Walker classification (1=Straight, 2=Wavy, 3=Curly, 4=Coily) |
| `textureType` | `string \| null` | Subtype like `'3B'`, `'2A'`, `'4C'` |
| `lengths` | `{ top, sides }` | Current lengths (`'bald' \| 'stubble' \| 'short' \| 'medium' \| 'long'`) |
| `density` | `'thin' \| 'medium' \| 'thick' \| null` | Hair density |
| `cutFamily` | `string \| null` | `'fade' \| 'taper' \| 'buzz' \| 'scissor' \| 'longer_scissor' \| 'other'` |
| `styleNature` | `'natural' \| 'protective' \| 'heat-styled' \| null` | How the hair is maintained |
| `coverage` | `'full' \| 'thinning' \| 'sparse' \| 'patchy' \| null` | Coverage level |
| `faceShape` | `string \| null` | `'oval' \| 'round' \| 'square' \| 'diamond' \| 'heart' \| 'oblong'` |

### Salon Fields

| Field | Type | Description |
|-------|------|-------------|
| `colorTechnique` | `string \| null` | e.g. `'balayage'`, `'highlights'`, `'ombre'` |
| `layeringMethod` | `string \| null` | e.g. `'long layers'`, `'blunt cut'` |
| `stylingMethod` | `string \| null` | e.g. `'blowout'`, `'air-dried'` |
| `volumeLevel` | `string \| null` | `'flat' \| 'low' \| 'medium' \| 'high' \| 'voluminous'` |

### Glasses Fields

| Field | Type | Description |
|-------|------|-------------|
| `frameSizeCategory` | `string \| null` | `'small' \| 'medium' \| 'large' \| 'extra-large'` |
| `bridgeCategory` | `string \| null` | `'narrow' \| 'medium' \| 'wide'` |
| `frameShape` | `string \| null` | Frame shape description |

## API Access

Fetch a user's card via the `appearance:card` scope:

```bash
curl https://api.appearance.app/v1/users/me/card \
  -H "X-Appearance-API-Key: ak_your_key" \
  -H "Authorization: Bearer at_user_token"
```

For the full 50+ field profile, see [Appearance Profile](/concepts/appearance-profile).

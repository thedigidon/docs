title: "For AI Agents"
description: "Connect any AI agent to a user's Appearance ID."
---

Any agent that generates images of people can connect to Appearance ID and receive reference photos of the user.

## Connect

The Appearance API is an MCP server at `https://appearance.app/api/mcp`.

## Example

```
User: "What would I look like with a buzz cut?"
Agent: [calls get_appearance → receives reference photos]
Agent: [generates image using own model with photos as reference]
Agent: [calls save_generation → result stored in user's profile]
```

## Tools

| Tool | Description |
|------|-------------|
| `get_appearance` | Get the user's reference photos |
| `save_generation` | Save a generated image to the user's profile |
| `list_generations` | Browse the user's generation history |
| `search_styles` | Search styles on Appearance |

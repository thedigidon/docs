Any agent that needs to know what a user looks like can integrate with Appearance through standard protocols.

## Discovery

### MCP Server

Appearance exposes a [Model Context Protocol](https://modelcontextprotocol.io) server. Any MCP-compatible client can query documentation and API definitions directly.

<Tabs>
  <Tab title="Claude Code">
    ```bash
    claude mcp add --transport http appearance https://docs.appearance.app/mcp
    ```
  </Tab>
  <Tab title="Cursor">
    ```json

      "mcpServers": {
        "appearance": {
          "url": "https://docs.appearance.app/mcp"
        }
      }
    }
    ```
  </Tab>

## How agents use Appearance

### Reading appearance data

The agent calls the API with the user's token and receives structured data it can use directly.

```
User: "What kind of glasses would suit me?"
Agent: [calls GET /v1/users/me/appearance]
Agent: "You have an oval face shape with a face width of 142mm.
        Medium frames with a bridge width around 18mm would fit well."
```

### Enriching other tasks

The agent reads appearance data to personalize work that isn't directly about appearance.

```
Agent building a travel packing list:
  → Reads user's appearance data
  → Knows user has curly hair, type 3B
  → Includes curl-friendly travel products
```

### Creating an appearance

If the user doesn't have an Appearance profile, the agent can initiate one.

```bash
curl -X POST https://api.appearance.app/v1/scans/initiate \
  -H "X-Appearance-API-Key: ak_your_key" \
  -d '{ "redirectUrl": "https://yourapp.com/callback" }'
```

```json
{
  "sessionId": "scan_k7Xm9pL2qR4v",
  "scanUrl": "https://appearance.app/scan?session=scan_k7Xm9pL2qR4v",
  "expiresAt": "2026-03-29T11:30:00Z"
}
```

The user opens `scanUrl`, completes a ten-second face scan, and your app receives a callback when their profile is ready.

## Authentication

| Header | Purpose |
|--------|---------|
| `X-Appearance-API-Key: ak_...` | Identifies your app |
| `Authorization: Bearer at_...` | Identifies the consenting user |

Both headers are required for all user-scoped requests.

## Rate limits

| Scope | Limit |
|-------|-------|
| Per API key | 60 requests/minute |
| Per user token | 120 requests/minute |

## Option A: MCP (recommended for agents)

The fastest way for an AI agent to access a user's Appearance ID is through the MCP server.

### 1. Get a dev token

Request API access to receive your development bearer token.

### 2. Connect your MCP client

<Tabs>
  <Tab title="ChatGPT">
    Register the Appearance MCP server as a ChatGPT app connector:
    ```
    URL: https://appearance.app/api/mcp
    Transport: HTTP POST
    Auth: Bearer token
    ```
  </Tab>
  <Tab title="Claude Code">
    ```bash
    claude mcp add --transport http appearance https://appearance.app/api/mcp \
      --header "Authorization: Bearer YOUR_TOKEN"
    ```
  </Tab>
  <Tab title="Cursor">
    ```json
    {
      "mcpServers": {
        "appearance": {
          "url": "https://appearance.app/api/mcp",
          "headers": {
            "Authorization": "Bearer YOUR_TOKEN"
          }
        }
      }
    }
    ```
  </Tab>
</Tabs>

### 3. Call `get_appearance`

Your agent can now call tools on the MCP server. The primary tool is `get_appearance`:

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "get_appearance",
    "arguments": {}
  }
}
```

## Option B: REST API

For non-agent integrations, the same data is available via REST.

### 1. Authenticate a user

Redirect the user to the Appearance authorization screen:

```bash
https://appearance.app/oauth/authorize
  ?client_id=YOUR_ID
  &scope=appearance:read,generations:read
  &response_type=code
```

### 2. Exchange the code for tokens

```bash
curl -X POST https://appearance.app/api/oauth/token \
  -H "Content-Type: application/json" \
  -d '{
    "grant_type": "authorization_code",
    "code": "AUTH_CODE",
    "client_id": "YOUR_CLIENT_ID",
    "client_secret": "YOUR_SECRET"
  }'
```

### 3. Read the user's Appearance ID

```bash
curl https://appearance.app/api/v1/users/me/appearance \
  -H "Authorization: Bearer at_user_token"
```

The response shape is identical to the MCP `get_appearance` tool above.

## Available tools

| Tool | Scope | Description |
|------|-------|-------------|
| `get_appearance` | `appearance:read` | Face images + Look descriptors |
| `get_scan_grid` | `appearance:read` | Face images only (lighter) |
| `search_styles` | `styles:search` | Search business styles |
| `save_generation` | `generations:write` | Save a result to the user's timeline |
| `list_generations` | `generations:read` | Browse generation history |

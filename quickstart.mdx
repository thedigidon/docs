## Overview

The Appearance API gives you structured appearance data for any consenting user — hair type, face shape, density, coloring, measurements, and more. No questionnaires. No photo uploads. One API call.

<Note>
  The Appearance API is currently in private beta. Request access at developers@appearance.app.
</Note>

## Step 1: Get API Credentials

Request API access to receive:
- **API Key** (`ak_...`) — identifies your application
- **OAuth Client ID + Secret** — for the "Sign in with Appearance" user flow

## Step 2: Authenticate a User

Implement the "Sign in with Appearance" OAuth flow to get a user's access token:

```bash
# 1. Redirect user to Appearance authorization
https://appearance.app/oauth/authorize?client_id=YOUR_ID&scope=profile,appearance:profile&response_type=code

# 2. Exchange the authorization code for tokens
curl -X POST https://api.appearance.app/v1/oauth/token \
  -H "Content-Type: application/json" \
  -d '{
    "grant_type": "authorization_code",
    "code": "AUTH_CODE",
    "client_id": "YOUR_CLIENT_ID",
    "client_secret": "YOUR_SECRET"
  }'
```

## Step 3: Fetch the User's Appearance Profile

```bash
curl https://api.appearance.app/v1/users/me/profile \
  -H "X-Appearance-API-Key: ak_your_key" \
  -H "Authorization: Bearer at_user_token"
```

## 1. Get credentials

Request API access to receive your API key (`ak_...`) and OAuth client credentials.

## 2. Authenticate a user

Redirect the user to the Appearance authorization screen. They see their own profile, choose what to share, and approve.

```bash
# Redirect to authorization
https://appearance.app/oauth/authorize?client_id=YOUR_ID&scope=profile,appearance:read&response_type=code

# Exchange the code for tokens
curl -X POST https://api.appearance.app/v1/oauth/token \
  -H "Content-Type: application/json" \
  -d '{
    "grant_type": "authorization_code",
    "code": "AUTH_CODE",
    "client_id": "YOUR_CLIENT_ID",
    "client_secret": "YOUR_SECRET"
  }'
```

## 3. Read the user's appearance

```bash
curl https://api.appearance.app/v1/users/me/appearance \
  -H "X-Appearance-API-Key: ak_your_key" \
  -H "Authorization: Bearer at_user_token"
```

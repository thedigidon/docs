<Note>
  The Appearance API is in private beta. Request access at developers@appearance.app.
</Note>

## 1. Get a dev token

Request API access to receive your bearer token.

## 2. Connect your MCP client

<Tabs>
  <Tab title="ChatGPT">
    Register the Appearance MCP server as a ChatGPT app connector:
    ```
    URL: https://appearance.app/api/mcp
    Transport: HTTP POST
    Auth: Bearer token
    ```
  </Tab>
  <Tab title="Claude Code">
    ```bash
    claude mcp add --transport http appearance https://appearance.app/api/mcp \
      --header "Authorization: Bearer YOUR_TOKEN"
    ```
  </Tab>
  <Tab title="Cursor">
    ```json
    {
      "mcpServers": {
        "appearance": {
          "url": "https://appearance.app/api/mcp",
          "headers": {
            "Authorization": "Bearer YOUR_TOKEN"
          }
        }
      }
    }
    ```
  </Tab>
</Tabs>

## 3. Get the user's photos

Call `get_appearance` to receive the user's reference photos:

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "get_appearance",
    "arguments": {}
  }
}
```

You'll receive multi-angle photos and a composite scan grid. Use these as reference to generate images of the user with your own models.

## 4. Save results back

After generating an image, store it in the user's profile:

```json
{
  "jsonrpc": "2.0",
  "id": 2,
  "method": "tools/call",
  "params": {
    "name": "save_generation",
    "arguments": {
      "imageUrl": "https://your-service.com/generated/abc123.jpg",
      "zone": "hair",
      "styleName": "Curtain Bangs"
    }
  }
}
```

The result appears in the user's Appearance app alongside results from every other connected service.

## Available tools

| Tool | Description |
|------|-------------|
| `get_appearance` | Get the user's reference photos |
| `get_scan_grid` | Get just the scan grid image |
| `save_generation` | Save a generated result to the user's profile |
| `list_generations` | Browse the user's generation history |
| `search_styles` | Search styles from businesses on Appearance |

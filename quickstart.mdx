## Overview

The Appearance API lets you access a user's appearance data — hair type, face shape, style preferences — and check compatibility between users and offerings. Here's how to get started.

<Note>
  The Appearance API is currently in private beta. Request access at developers@appearance.app.
</Note>

## Step 1: Get API Credentials

Request API access to receive:
- **API Key** (`ak_...`) — identifies your application
- **OAuth Client ID + Secret** — for "Sign in with Appearance" user flow

## Step 2: Authenticate a User

Implement the "Sign in with Appearance" OAuth flow to get a user's access token:

```bash
# 1. Redirect user to Appearance authorization
https://appearance.app/oauth/authorize?client_id=YOUR_ID&scope=profile,appearance:card&response_type=code

# 2. Exchange the authorization code for tokens
curl -X POST https://api.appearance.app/v1/oauth/token \
  -H "Content-Type: application/json" \
  -d '{
    "grant_type": "authorization_code",
    "code": "AUTH_CODE",
    "client_id": "YOUR_CLIENT_ID",
    "client_secret": "YOUR_SECRET"
  }'
```

## Step 3: Fetch the User's Appearance Card

```bash
curl https://api.appearance.app/v1/users/me/card \
  -H "X-Appearance-API-Key: ak_your_key" \
  -H "Authorization: Bearer at_user_token"
```

Response:
```json
{
  "cardType": "user",
  "zone": "hair",
  "textureFamily": 3,
  "textureType": "3B",
  "lengths": { "top": "short", "sides": "short" },
  "density": "thick",
  "faceShape": "oval",
  "audience": "masculine",
  "computedAt": "2026-03-29T10:30:00Z",
  "cardVersion": 1
}
```

## Step 4: Check Compatibility

Compare the user against an offering:

```bash
curl -X POST https://api.appearance.app/v1/compatibility/check \
  -H "X-Appearance-API-Key: ak_your_key" \
  -H "Authorization: Bearer at_user_token" \
  -H "Content-Type: application/json" \
  -d '{ "offeringId": "off_abc123" }'
```

Response:
```json
{
  "total": 78,
  "tiers": {
    "nature": 0,
    "texture": 30,
    "length": 20,
    "density": 7,
    "coverage": 0,
    "faceShape": 15,
    "styleDim": 6
  }
}
```

## Step 5: Get Recommendations

Fetch personalized style recommendations:

```bash
curl "https://api.appearance.app/v1/recommendations?zone=hair&limit=10" \
  -H "X-Appearance-API-Key: ak_your_key" \
  -H "Authorization: Bearer at_user_token"
```

Response:
```json
{
  "recommendations": [
    {
      "offeringId": "abc123",
      "businessId": "biz456",
      "score": 82.5,
      "compatible": true,
      "tiers": {
        "nature": 0,
        "texture": 24,
        "length": 20,
        "density": 15,
        "coverage": 0,
        "faceShape": 15,
        "styleDim": 6
      }
    }
  ]
}
```

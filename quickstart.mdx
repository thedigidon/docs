<Note>

</Note>

## 1. Get a token

Request API access to receive your bearer token.

## 2. Connect

<Tabs>
  <Tab title="ChatGPT">
    ```
    URL: https://appearance.app/api/mcp
    Transport: HTTP POST
    Auth: Bearer token
    ```
  </Tab>
  <Tab title="Claude">
    ```bash
    claude mcp add --transport http appearance https://appearance.app/api/mcp \
      --header "Authorization: Bearer YOUR_TOKEN"
    ```
  </Tab>
  <Tab title="Cursor">
    ```json
    {
      "mcpServers": {
        "appearance": {
          "url": "https://appearance.app/api/mcp",
          "headers": {
            "Authorization": "Bearer YOUR_TOKEN"
          }
        }
      }
    }
    ```
  </Tab>
</Tabs>

## 3. Get the user's photos

```json
{
  "method": "tools/call",
  "params": { "name": "get_appearance", "arguments": {} }
}
```

```json
{
  "ok": true,
  "data": {
    "photos": [
      "https://appearance.app/photos/usr_k7Xm/1.jpg",
      "https://appearance.app/photos/usr_k7Xm/2.jpg",
      "https://appearance.app/photos/usr_k7Xm/3.jpg",
      "https://appearance.app/photos/usr_k7Xm/4.jpg"
    ],
    "updatedAt": "2026-03-29T10:30:00Z"
  }
}
```

Use these photos as reference to generate images of the user with your own models.

## 4. Save the result

```json
{
  "method": "tools/call",
  "params": {
    "name": "save_generation",
    "arguments": {
      "imageUrl": "https://your-service.com/generated/abc123.jpg",
      "zone": "hair"
    }
  }
}
```

The result appears in the user's Appearance profile alongside results from every other connected service.

## Tools

| Tool | Description |
|------|-------------|
| `get_appearance` | Get the user's reference photos |
| `save_generation` | Save a generated image to the user's profile |
| `list_generations` | Browse the user's generation history |
| `search_styles` | Search styles on Appearance |
